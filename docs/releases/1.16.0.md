## DeepSeek++ 1.16.0

1.16.0 是统一工具调用与可靠运行版本：子智能体从对话的第一条消息起就能派生；无论模型输出的工具标记多么不规则，每一次工具调用都会被完整捕获；工具调用文本在刷新与回看后被干净隐藏；长时间无响应的运行由看门狗兜底，永远不会无声卡死。

### 主要变化

- **第一条消息即可派生子智能体**：内联智能体从对话的第一个回合起就能看到完整工具目录（包括派生子智能体），模型可以在任务一开始就并行拆分工作；派生的子任务在结构化执行界面中全程可见、可追踪。
- **每一次工具调用都被完整捕获**：无论模型输出的工具标记分隔符如何错位、多余或未闭合，都能被识别并规范化；能执行的工具调用照常执行，确实无法解析的会给出清晰的错误反馈并让模型重试，工具调用绝不会被当作普通文字漏掉。
- **刷新与回看不再出现原始工具标记**：对话刷新、恢复或回看历史时，已执行的工具调用文本会被干净地隐藏，不再以生硬的标记文本出现在聊天气泡里。
- **运行永不无声卡死**：即使模型长时间没有任何响应，运行也会在超时后明确结束并给出可见的错误提示；页面关闭时未完成的运行会被如实标记为已停止，不再留下永远转圈的「运行中」状态。
- **工具调用文本隐藏后不留多余按钮**：被隐藏内容的消息不再提供编辑、复制等对其无意义的操作按钮，消息操作与可见内容保持一致。
- **排版统一**：扩展各个界面的字号与排版使用一致的字号体系，运行结束后恢复的控制台与页面原生排版保持协调。
- **工具结果更干净**：工具返回内容中的终端转义字符会在交给模型之前被清理，模型读到的是干净的文本。
- **回看更完整**：运行结束后的刷新中，控制台保留每一步的工作记录与思考过程，且不再把中间步骤误显示为独立气泡（包括不再重复弹出上一回合更完整的旧回答）。
- **权限变化**：Chrome、Edge 和 Firefox 均不新增浏览器权限。
