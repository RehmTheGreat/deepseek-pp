## DeepSeek++ 1.15.1

1.15.1 是内联智能体工具调用体验整合版本：所有工具调用统一在结构化执行界面中展示与续跑，移除易卡住的「已调用工具」折叠计数块；工具中途不可用时有清晰的降级提示；子智能体派生与长任务上下文压缩正式可用，运行结束后的控制台回看也更完整。

### 主要变化

- **统一的工具调用界面**：每一次执行了工具的回合都直接进入结构化内联智能体界面，逐步展示工具调用过程；移除旧的「Called tools (n)」折叠计数块，不再出现计数卡住不动的情况。
- **工具调用始终可见续跑**：模型发出工具调用后一律在结构化界面中继续执行，调用步骤、结果与后续回答连贯可追踪。
- **工具中途不可用的清晰处理**：运行过程中某些工具变为不可用时，不再直接报红色错误——过期的工具条目会自动校正，并明确告知模型哪些工具已不可用，运行继续推进。
- **子智能体派生可用**：内联智能体每回合都能看到完整工具目录（包括派生子智能体），模型可以在任务中实际派生子智能体并行处理，全程在界面中可见。
- **长任务更省 Token**：长对话的智能体运行会在上下文过长时自动压缩早期内容，任务不中断、思路不丢失，长运行更省额度。
- **运行结束后的回看更完整**：运行完成后的恢复与刷新中，控制台继续保留每个工具调用条目，最终回答以完整字号展示，方便回看整个执行过程。
- **权限变化**：Chrome、Edge 和 Firefox 均不新增浏览器权限。

### 验证

- `npm run compile`
- `npm run prompt:freeze`
- `npm run build:chrome`，随后执行扩展密钥注入（`node scripts/inject-extension-key.mjs …`）
- `npm run verify:manifest-policy`
