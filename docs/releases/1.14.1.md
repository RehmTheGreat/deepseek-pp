## DeepSeek++ 1.14.1

1.14.1 是内联智能体运行可靠性修复版本：流中断后自动续跑、工具执行与提交前验证都有超时上限、畸形工具调用可恢复且状态记录如实，长任务不再因单次网络抖动或一个卡住的调用而整体失败。

### 主要变化

- **中断自动续跑**：流式输出中途断开时，内联智能体会从断点自动续跑（每次运行最多 3 次），任务不再因一次网络或页面中断而失败；续跑提示按内部回合识别，不打乱会话链。
- **已输出的回合绝不重复提交**：服务器已经开始输出的回合一旦出错，直接标记为中断，不再用同一会话锚点重试，避免重复消息与会话链分叉。
- **工具执行 180 秒超时**：卡住的工具调用不再冻结整个智能体运行，超时后以可重试的错误记录返回，运行继续推进（仅限智能体运行内的调用，普通聊天中的工具调用行为不变）。
- **提交前验证 20 秒超时**：每次提交前的验证挑战阶段有了超时上限，手动停止也会立即生效，不再出现永久等待。
- **畸形工具调用恢复**：闭合标记不匹配的工具调用不再被静默丢弃（也不再吞掉其后并行的调用），所有解析路径都会将其恢复为带错误码的结构化记录，且保证不重复执行。
- **运行状态如实呈现**：被新消息接管或手动停止的智能体运行，在历史记录中不再永远显示「运行中」，恢复后校正为真实的终态。
- **权限变化**：Chrome、Edge 和 Firefox 均不新增浏览器权限。

### 验证

- 全量 `npm test`（除基线已知的 4 项 Windows 本地环境性失败外全部通过；该 4 项在改动前的基线上同样失败，Linux CI 不受影响）
- `npm run compile`
- `npm run prompt:freeze`
- `npm run verify:i18n`
- `npm run build:chrome`，随后执行扩展密钥注入（`node scripts/inject-extension-key.mjs …`），未打包安装的扩展 ID 保持不变
